ALT TEXT — Speak Frankly store assets
=====================================

Google Play has no alt-text field for screenshots today. These exist so the
same descriptions can be reused on the website, in press/ASO tools, and in any
accessibility context — and so anyone editing the listing later can tell at a
glance what each image is supposed to prove.

Written to describe what is ACTUALLY VISIBLE. If a screenshot is recaptured and
its content changes, update the matching entry here.

STATUS: written against the delivered files. Two entries describe a screen that
is thinner than intended — see the notes marked LIMITATION — because those
states could not be produced without a human voice or more usage history.
